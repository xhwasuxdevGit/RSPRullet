# 보정 내역과 알려진 함정 (portfolio-gdoc)

`check_format.py`에 ✗가 남아 손으로 고쳐야 할 때만 읽는다.

## 1. `postfix.py`가 처리하는 것
- 기본: 페이지 없음, 단락 간격 모드 `NEVER_COLLAPSE`, 전체 글꼴, 문서 제목(TITLE), 문서 제목 간격, 표 열 너비(2열 130/368pt, 그 외 498pt 비례)·머리행 고정, 구분선 단락 분리(빈 줄 + 구분선), 표 뒤 빈 줄.
- 추가 보정(`--extra-only`로 따로 낼 수 있음): 제목·장·절 제목 간격·다음 단락과 함께·굵게(HTML 변환이 굵게 해제를 박아 둠), 모든 목록 들여쓰기와 연속 단락 들여쓰기(바로 앞 항목의 글자 위치), 표 글자 크기·셀 단락 줄간격·간격(머리행 1.0·앞뒤 0, 본문 행 1.5·앞 간격 = 셀 글자 크기)·머리행·첫 열 굵게, 본문·목록 단락 간격, 절 앞 빈 줄 크기, 마침표 분리(`. `의 공백을 줄바꿈으로, 목록이면 새 단락의 글머리 해제 + 들여쓰기).
- 문서에 이미 같은 값이 들어간 스타일·표 요청은 출력에서 뺀다(뺀 개수는 stderr). 그래서 다시 돌려도 바뀐 부분만 나온다.
- 굵게 범위(간격 3자 이하)와 이어진 같은 단락 스타일은 합쳐서 요청 수를 줄인다(다른 요청이 사이에 끼어 있어도 단락이 이어지면 합친다).

## 2. 알려진 함정
- 새 문서 기본 단락 간격 모드는 `COLLAPSE_LISTS`라 목록 항목 사이 간격이 첫 항목에만 남는다 → 보정 필수.
- 문서 첫 단락들은 HTML 변환 때 간격 0으로 들어간다 → 보정에서 맞춘다.
- 표 머리행 셀 단락은 줄간격 1.0·앞뒤 0이어야 한다. 줄간격이 크면 세로 가운데 정렬이 어긋나 보이고, 변환 때 셀 여백이 단락 앞뒤 6pt로도 들어가 겹친다. 문서 전체 줄간격을 바꿀 때 표 안은 제외한다.
- 표 테두리는 셀마다 지정된다. 나중에 행·열을 추가하면 새 셀에 검정 기본 테두리가 붙을 수 있다고 보고에 적는다.
- 목록 단계를 바꿀 때: `deleteParagraphBullets` → **들여쓰기 0으로 초기화** → 단계 수만큼 탭 삽입 → `createParagraphBullets`. 초기화하지 않으면 기존 들여쓰기가 더해져 한 단계 더 깊어진다.
- 같은 길이로 바꾸는 편집(`, `→`,\u000b`, `\u000b`→`\n`)은 위치가 변하지 않아 한 묶음에 넣을 수 있다. `replaceAllText` 뒤에는 위치가 바뀔 수 있으니 위치 기반 요청 전에 다시 읽는다.
- 번호 목록 사이에 연속 단락(`<p class="cont">`)이 끼면 번호가 1부터 다시 시작할 수 있다 → 검증 후 위 목록 단계 절차로 고친다.
